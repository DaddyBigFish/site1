Services

What we test

The engagement is three days. Spend them on one of these, or split them across any mix in the same test.

Cyber Essentials

A technical assessment of infrastructure, end-user devices, internet-facing services and cloud against Cyber Essentials v3.3. Firewalls, configuration, access control and malware protection, with evidence. Findings that would prevent certification are identified so they can be fixed.

Web application and API

Manual testing of web applications and APIs, against OWASP. Authentication, injection, business logic and access control.

Internal infrastructure

Services and software on a defined network range, authenticated or not. Misconfiguration, exposure and known weaknesses.

Attack path simulation

The estate in scope. From supplied credentials or a corporate device, paths through on-premises and cloud to a stated objective, usually administrative control.
